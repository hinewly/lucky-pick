# LuckyPick · 个人幸运号码生成器

> 用你的星座、幸运数字、梦境，生成属于你的号码。

一个**个人娱乐工具**，不是博彩工具。基于经过实战验证的算法扩展而来，加上"用户因素库"让你对号码有"参与感"。

---

## 特点

- 🎲 **个性化因素** — 星座、梦境、生日、幸运数字，可叠加
- 📱 **PWA** — 装到手机桌面像 App 一样用，可离线
- 🧮 **算法底座** — 继承自原彩票选号算法（5 策略权重合成）
- 🎯 **透明诚实** — 所有权重可调，不保证中奖，明确标注"娱乐用途"

---

## 一键体验

打开 `public/index.html` 即可使用，或用本地服务：

```bash
cd public && python3 -m http.server 8765
# 浏览器访问 http://localhost:8765
```
