## 一、产品定位

> **个人幸运生成器** — 用你的星座、幸运数字、梦境等，生成属于你的号码。

副标题：
- 中文：用你的星座、幸运数字、梦境，生成属于你的幸运号码

定位调整：
- ~~彩票选号工具~~ → ✅ 个人幸运生成器
- "彩票"在国内/海外有政策敏感
- "个人幸运生成器"听起来更有趣味，适用范围更广

---

## 二、核心价值主张

> **让用户感觉"我参与了决策"，而不是"系统给我一个号码"。**

**心理学基础**：Illusion of Control（控制错觉）
- 自选号码的人比机选的人复购率高 40%+
- 这是已被验证的认知偏差

所以这个产品本质上是：**合理利用认知偏差，给用户更好的心理体验**。

---

## 三、双线策略

| 维度 | 国内 | 国外 |
|------|------|------|
| **优先级** | 短期 | 长期 |
| **收费** | 免费（用户对收费敏感） | Freemium + 订阅 |
| **市场** | 大乐透、七星彩 | Powerball、Mega Millions、EuroMillions |
| **支付** | 自愿打赏（可选） | Stripe 月订 $1.99 / 年订 $9.99 / 终身 $29.99 |

**共享部分**：算法、UI 组件、状态管理、本地存储、PWA 基础设施
**差异部分**：语言、彩种、合规文案、支付集成

---

## 四、技术选型

### 形态：**Progressive Web App (PWA)**

**核心优势**：
- 跨平台一套代码
- 添加到主屏像 App
- 离线可用
- 一秒启动
- 不需应用商店审核
- 体积小（1-3 MB）
- URL 分享

### 技术栈

- 前端：HTML + CSS + 原生 JavaScript
- Service Worker：实现离线缓存
- Web App Manifest：配置图标、名称、启动画面
- localStorage：本地存储用户因素、历史
- 托管：Cloudflare Pages（推荐）或 GitHub Pages

**不需要**：后端、数据库、用户账号、重型框架

## 五、产品功能

### 因素库（4 大类）

**时间类**：今天日期、生日、纪念日、重要年份
**数字类**：幸运数字、任意数字、名字首字母
**玄学类**：星座（西方 + 中国）、梦境、数字命理（Life Path Number）
**游戏化**：转盘、老虎机、闪烁卡片（规划中）

- localStorage 持久化
- PWA 基础（manifest + Service Worker）

### 计划中

- 塔罗牌、转盘动画

## 六、合规边界（重要）

### 🟢 可以做

- ✅ 生成号码的工具
- ✅ 用户输入自己的玄学因素
- ✅ 保存历史记录、做统计图表
- ✅ "运势解读"作为娱乐内容（明确标注"仅供娱乐"）

### 🔴 不能碰

- ❌ 直接卖彩票、代购、合买
- ❌ 声称"提高中奖率""保证中奖"
- ❌ 声称"内部数据""破解算法"
- ❌ "专家预测"并收费

### 必须写进产品

```
本应用仅供个人娱乐，所生成的号码不保证任何中奖概率。
彩票是随机的，请理性对待，量力而行。未成年人禁止使用。
```
